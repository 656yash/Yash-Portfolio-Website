# Yash Deshpande — Creative Pinboard Portfolio

An interactive, tactile creative pinboard developer portfolio built for **Yash Deshpande** (B.Tech Information Technology, MIT Academy of Engineering Pune · Batch 2024–2028).

Designed with a green cutting-mat pinboard surface, realistic paper textures (kraft brown, canary yellow, vintage cream, and crisp white), masking tape, pushpins, interactive project dossiers, and an integrated PDF resume viewer.

## 🚀 Live Demo & Deployment
- **Deployment Platform**: Vercel (Configured with `vercel.json` SPA routing)
- **Framework**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS v4 + Lucide Icons

## 📌 Key Features
- **Tactile Pinboard Aesthetic**: Authentic shadows, layered paper sheets, realistic pushpins, scotch tape, and vintage rubber stamps.
- **Project Dossiers & Artifacts**: Detailed inspection modal for projects including live apps, demo sites, GitHub repositories, and architecture breakdown.
- **Interactive Resume Modal**: In-browser PDF view of official resume (`/Yash_Deshpande_Resume.pdf`), printable dossier tab, and direct download buttons.
- **Experience & Telemetry**: Industrial data science internship at Reliance Industries (ROGC Sensor Anomaly Detection), hackathons (Winner Offgrid 1.0, Finalist CodeVerse, Top 50 TechFest IIT Bombay).
- **Interactive Contact Postcard**: Vintage airmail postcard design with direct email dispatch and social links.

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start local dev server
npm run dev

# Build production bundle
npm run build

# Preview build locally
npm run preview
```
